# Synthetic counting example

These labels and counts are invented solely for this documentation fixture. Each count is the number of synthetic shapes with that label.

| Label | Count |
| --- | --- |
| Blue circle | 3 |
| Green square | 2 |

The total count is 5, calculated by adding the 3 blue circles and 2 green squares. The labels do not refer to people, customers, systems, accounts, or environments.
