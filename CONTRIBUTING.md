# Contributions and support

This repository contains synthetic documentation for publication-control tests and has no production consumers or product support commitment.

GitHub Issues are disabled. Send questions, bug reports, and feature requests privately to [cs-platform@com2us.com](mailto:cs-platform@com2us.com). GitHub is not a customer support channel, and no response or fix completion SLA is offered.

External pull requests are not reviewed or merged and will be closed with a reminder to use the contact above. Release Bot promotion pull requests are different: they are the controlled update path for this repository.

Do not include private data or credentials in a pull request. Report security concerns privately through the channel in [SECURITY.md](SECURITY.md).
